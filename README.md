# InfoAquarium

> Динамический граф как информационный аквариум — путешествие по смыслу через стеклянный муравейник.

Граф одновременно является **картой мира** и **движком графики**: узлы — понятия/заметки, рёбра — связи и пути путешественника, треугольники Делоне между узлами — цветной ландшафт (горы, долины, пещеры). Пространство — живое: физическая симуляция двигает узлы каждый кадр.

---

## Структура

```
1-browser/        Автономный прототип — один HTML-файл (index.html), работает без сборки
2-react/          React + Vite + react-force-graph (3D) + Delaunay terrain + InfoM UI
3-obsidian/       Плагин Obsidian (TypeScript, src/main.ts) — граф из твоих заметок как живой аквариум
```

## 1. Browser Prototype

Открыть напрямую в браузере:

```bash
open 1-browser/index.html
# или
python3 -m http.server 8080 --directory 1-browser
```

**Управление:**
- Клик на узел — путешественник строит BFS-маршрут до цели
- Перетащить фон — панорама
- Колесо мыши — зум
- Клавиши режимов: `H` — гиперболическая проекция (диск Пуанкаре), `G` — игровой режим, `V` — ячейки Вороного, `C` — режим кроссворда, `E` — редактор узлов, `Q` — гексагональная сетка Q6, `/` — панель запросов InfoM

**Что внутри:**
- Физика: отталкивание (Кулон) + пружины (Гук) + демпфирование + кластерное притяжение к архетипам
- Триангуляция Делоне (и оверлей Вороного) — треугольники между узлами, раскрашенные по семантической категории
- Путешественник (`traveler`) и мультиагентный режим (5 агентов в браузере, 4 в Obsidian) со следами феромонов ACO
- Поиск пути: BFS по графу и синтез звука Web Audio

## 2. React App

```bash
cd 2-react
npm install
npm run dev
```

**Стек:** React 18 · Vite · `react-force-graph` (Three.js WebGL) · `delaunator` · `d3-delaunay`

**Ключевые компоненты (`2-react/src/`):**
- `App.jsx`, `data.js` — 3D-граф с физикой (`d3-force-3d`), 3-уровневая иерархия (detail → strategy → archetype: Бытие / Поток / Познание / Структура), временной ползунок эпох, полёт камеры к узлу
- `components/TerrainOverlay.jsx` — треугольники Делоне и режим Вороного (`V`) поверх 3D-сцены
- `components/SemanticZoom.jsx` — карточка деталей узла при приближении камеры
- `components/AgentHUD.jsx`, `hooks/useAudio.js` — панель агентов, игровая цель и Web Audio
- `components/InfoPanel.jsx`, `components/QueryPanel.jsx`, `components/Q6Overlay.jsx`, `hooks/useInfoM.js` — подключение к бэкенду InfoM GraphRAG (`/stats`, `/query`, `/index`), Q6-сетка (клавиша `Q`) и панель запросов

## 3. Obsidian Plugin

```bash
cd 3-obsidian
npm install
npm run build
```

Скопировать `main.js` + `manifest.json` в папку плагина Obsidian:
```
<vault>/.obsidian/plugins/info-aquarium/
```

**Команда:** `InfoAquarium: Open InfoAquarium graph`
**Иконка:** `git-fork` в левой панели

**Что делает:**
- Читает все заметки vault через `MetadataCache`
- Строит граф: заметки = узлы, внутренние ссылки `[[...]]` = рёбра
- Размер узла пропорционален числу ссылок
- Живая физика, триангуляция Делоне/Вороного, гиперболическая проекция (`H`), феромоны ACO, мультиагентность, Q6-сетка и подключение к InfoM
- Клик на узел — маршрут и фокус камеры
- Если vault пуст — показывает 16-узловой иерархический демо-граф

## Концепция

| Метафора | Техника |
|----------|---------|
| Стеклянный муравейник | Прозрачные узлы + terrain triangles |
| Рёбра = дороги мира | Путешественник движется только по рёбрам |
| Горы мира = полигоны | Delaunay triangulation + цвет по категории + 3D-рельеф (`fz = linkCount × 8`) |
| Мир внутрь, не наружу | Hyperbolic projection (диск Пуанкаре, преобразование Мёбиуса, `H`) |
| Время как измерение | Ползунок эпох, фильтрация рёбер |
| Информационный запах | ACO pheromone trails (испарение и нагрев цвета/ширины рёбер) |
| Семантическая иерархия и Q6 | 3 уровня (detail → strategy → archetype) + 8×8 Q6-сетка сообществ InfoM |
